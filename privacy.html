1. 本ポリシーについて

PROJECT T（以下「本サービス」）は、TEKKEN 8の対戦録画、YouTubeへの動画アップロード、対戦履歴の記録・閲覧、Discord等の外部アカウントとの連携機能を提供します。

本ポリシーでは、本サービスが取得・利用・保存・共有・削除する情報について説明します。

2. YouTube API Servicesの利用

本サービスはYouTube API Servicesを利用します。YouTube連携にはGoogle OAuth 2.0を使用し、GoogleまたはYouTubeのパスワードをPROJECT Tが取得・保存することはありません。

YouTube連携では、動画のアップロード（youtube.upload）と、連携したチャンネルの識別（チャンネルIDと名前の取得。youtube.readonly）の権限を要求します。要求した権限は、これらの目的以外には使用しません。

PROJECT Tによる、Google APIから受け取った情報の利用および他のアプリへの移転は、Google API Services User Data Policy（Limited Use［限定的な使用］の要件を含む）に従います。

PROJECT T's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • Google プライバシーポリシー
  • YouTube 利用規約
  • Googleアカウントの第三者アクセス管理

3. 取得する情報

アカウント・認証情報

Discordのパスワードは取得・保存しません。

  • OAuth Access Token、Refresh Token、許可されたscope
  • 機能提供に必要なYouTube API Data

録画・対戦履歴情報

  • 録画日時、動画の長さ・FPS・解像度等の動画情報
  • 対戦相手名、勝敗、取得ラウンド
  • 自分・相手のキャラクター、TEKKEN POWER

  • 録画動画との紐付け情報
  • 画像認識またはユーザー修正により得られた対戦情報

利用・セキュリティ情報

  • Recorder登録・解除履歴
  • APIアクセス、エラー、セキュリティ監査に必要なログ

4. 利用目的

  • PROJECT Tへのログイン、本人確認、アカウント連携
  • Discordからの録画操作およびRecorder・OBSとの連携
  • TEKKEN 8の対戦録画、整理、対戦履歴の作成・表示
  • ユーザーが許可したYouTubeチャンネルへの動画アップロード
  • YouTube動画とPROJECT Tの対戦履歴の紐付け
  • ユーザー本人が所有する動画・対戦履歴の表示
  • アップロード状態の管理、重複投稿防止、アップロード失敗時の再試行
  • 不正アクセス防止、障害対応、サービス品質の維持
  • ユーザーからの問い合わせ対応
  • 法令およびYouTube API Services等の適用ポリシーへの対応

本サービスは、取得した情報を上記と無関係な目的に無断で利用しません。

5. YouTubeに対する操作

本サービスは、ユーザーがGoogle OAuthを通じて明示的に許可したYouTubeチャンネルに限り動画をアップロードします。

アップロード時の動画のタイトル、説明、公開設定は、ユーザーが選択または許可した設定に基づいて登録します。

現在、本サービスはYouTube上の既存の動画を編集・削除しません。動画の管理・削除は、YouTube Studioから直接行えます。将来これらの機能を追加する場合は、必要な権限をGoogleの定める手続きに従って申請し、本ポリシーを更新したうえで、ユーザーの許可を得て提供します。

6. 第三者への提供・共有

本サービスは、ユーザーの個人情報、認証情報、YouTube API Dataを販売しません。

サービス提供に必要な場合に限り、Google / YouTube、Discordその他ユーザーが明示的に連携した外部サービスとの間で必要な情報を送受信します。また、法令に基づく場合等には必要な範囲で情報を開示することがあります。

7. Cookie等の利用

本サービスは、ログイン状態の維持、セッション管理、セキュリティ対策等のためにCookieその他の類似技術を使用する場合があります。

Google / YouTube等の埋め込みコンテンツにより、それぞれのサービスがCookie等を使用する場合があります。

広告について

本サービスのウェブサイトでは、第三者配信の広告サービス「Google AdSense」を利用しています。Googleなどの第三者配信事業者は、Cookieを使用して、ユーザーが本サイトや他のサイトに過去にアクセスした際の情報に基づいて広告を配信します。

Googleが広告Cookieを使用することにより、Googleやそのパートナーは、本サイトや他のサイトへのアクセス情報に基づいて、ユーザーに適切な広告を表示できます。

ユーザーは、Googleの広告設定で、パーソナライズ広告を無効にできます。また、www.aboutads.info にアクセスすると、第三者配信事業者のCookieによるパーソナライズ広告を無効にできます。詳しくは、Googleの広告に関するポリシーをご覧ください。

なお、YouTube API Servicesを通じて取得した情報（第2項・第3項）は、広告の配信や広告のための分析には使用しません。

9. 連携解除・データ削除

ユーザーはPROJECT Tのアカウント管理機能から、外部アカウントの連携解除、保存データの削除、PROJECT Tアカウントの削除を行うことができます。

PROJECT T上でYouTube連携を解除した場合、本サービスは可能な範囲でGoogleへの認可を失効させ、その認可に基づいて保存したAuthorized Dataを可能な限り速やかに削除し、YouTube API Servicesのポリシーに従って原則7暦日以内に削除します。

Google側からPROJECT Tへのアクセス権を解除することもできます。
Googleアカウントの第三者アクセス管理

PROJECT Tが独自に生成した対戦履歴等は、YouTube連携を解除しても、ユーザーが削除するまで保持される場合があります。

10. セキュリティ

本サービスは、取得した情報を不正アクセス、漏えい、改ざん等から保護するため、通信の暗号化、アクセス制御、OAuthによる認証、認証情報の保護、監査ログ等の適切な安全管理措置を講じます。

11. 本ポリシーの変更

サービス内容、利用するAPI、法令または外部サービスのポリシー変更等に応じて、本ポリシーを改定することがあります。重要な変更を行う場合は、本サービス上で適切な方法により通知します。

YouTube API Dataの利用目的等を、ユーザーが以前同意した範囲を超えて変更する場合には、必要に応じて改めて同意を取得します。

13. English summary

PROJECT T is a service for recording TEKKEN 8 matches, uploading the recordings to the user's own YouTube channel, keeping a match history, and linking Discord, Google and YouTube accounts. The Japanese text above is the full policy; this section summarizes the parts that concern YouTube API Services and Google user data.

YouTube API Services

PROJECT T uses YouTube API Services through Google OAuth 2.0. By using the YouTube features of PROJECT T, you also agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy. PROJECT T never receives or stores your Google or YouTube password.

Scopes requested and why

  • youtube.upload: to upload the match recordings that you choose to publish to the YouTube channel that you authorize.
  • youtube.readonly: to identify the authorized channel (channel ID and name), so that PROJECT T can show you which channel is connected and link your uploads to it.

Data we handle

For the YouTube features: your YouTube channel ID and name, IDs and metadata (title, description, privacy setting, status) of the videos that PROJECT T uploads, and OAuth tokens. Tokens are stored in encrypted form. We use this data only to provide the features described above. We do not sell it, and we do not use it for advertising.

Limited Use

PROJECT T's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Disconnecting and deleting your data

  • You can disconnect YouTube at any time on the PROJECT T login page. PROJECT T then revokes the authorization with Google where possible and deletes the data obtained through it as soon as possible, and in principle within 7 calendar days.
  • You can also revoke access from your Google account at myaccount.google.com/permissions.
  • You can delete your PROJECT T account and all data stored by PROJECT T with the 'アカウントとデータを削除' (Delete account and data) button on the login page. Videos already published on YouTube are not deleted by this.

Advertising

The PROJECT T website shows ads served by Google AdSense. Third-party vendors, including Google, use cookies to serve ads based on your prior visits to this website or other websites. Google's use of advertising cookies enables it and its partners to serve ads based on your visits to this and/or other sites on the Internet. You may opt out of personalized advertising by visiting Google Ads Settings, or opt out of a third-party vendor's use of cookies for personalized advertising at www.aboutads.info. See How Google uses information from sites that use its services. Data obtained through YouTube API Services is never used for advertising.
