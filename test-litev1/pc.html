PROJECT Tへログインし、Discord・Google・YouTubeなどの外部サービスを1つのPROJECT Tアカウントへ安全に連携します。

キャラを選んで、確認できた項目にチェックを入れていきます。チェックはこのブラウザに自動で保存されます。

キャラを選んで、コンボの確認やメモができます。自作コンボの登録のほか、収録コンボの編集・並べ替え・削除もできます。分類見出しの左の「⋮⋮」をドラッグすると、分類ごと入れ替えられます。内容はこのブラウザに自動で保存されます。

用語・よみ・別名・説明から検索できます。範囲（格ゲー共通／鉄拳）やカテゴリでも絞り込めます。

自キャラの確定反撃を、発生フレーム別に確認できます。相手の技から反撃の候補を逆引きすることもできます。

キャラを選ぶと、そのキャラの技の変更がある版が強調されます。全キャラ共通の変更・システムの変更もあわせて確認できます。

キャラを選ぶと、そのキャラの背景画像が小さく表示されます。画像をクリックすると、大きく拡大して見られます。

対戦履歴、録画動画、ラウンド、対戦内容を試合ごとにまとめて確認できます。

PROJECT Tが取得・利用・保存する情報と、外部サービス連携・データ削除について確認できます。

PROJECT Tの利用料金と、外部サービス利用時の費用について確認できます。

PROJECT T Recorderのダウンロードと、Windowsへのインストール手順を案内します。

PROJECT Tを使い始めるためのDiscord・Google・YouTube・TEKKEN ID・Discord Bot・OBSの導入方法をまとめています。

ステージごとのギミックを一覧で確認できます。画像をクリックすると詳しい説明が開きます。
